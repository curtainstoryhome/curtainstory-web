# สำรองการตั้งค่า LINE OA — CURTAIN STORY HOME

บัญชี `@curtainstoryhome` · โหมดตอบกลับ `chat` (ผู้รับผิดชอบตอบเอง)

## ทำไมโฟลเดอร์นี้ถึงมี

30 สิงหาคม 2569 พบว่าข้อความทักทายของร้านหายไปจากระบบ เหลือแต่ Default เปล่า
โดยไม่มีใครรู้ตัวว่าหายไปตั้งแต่เมื่อไหร่ ผลคือลูกค้าที่กดปุ่มไลน์จากโฆษณา Google
เข้ามา 129 ครั้งในหนึ่งเดือน แต่กลายเป็นเพื่อนจริงแค่ 3 คน เพราะเปิดเข้ามาเจอ
ห้องแชทว่างเปล่า ไม่รู้จะพิมพ์อะไร แล้วปิดทิ้ง

โฟลเดอร์นี้คือชุดที่ใช้กู้กลับได้ทันทีถ้าเกิดซ้ำ

## ไฟล์ในโฟลเดอร์

| ไฟล์ | คืออะไร | กู้กลับอย่างไร |
| --- | --- | --- |
| `richmenu.json` | โครงเมนู 6 ปุ่มใต้ห้องแชท พร้อมพิกัดและลิงก์ | `npm run line:richmenu:deploy` |
| `richmenu.jpg` | ภาพเมนูขนาด 2500x1686 | สร้างใหม่ได้ด้วย `npm run line:richmenu:image` |
| `richmenu-list.json` | เมนูทั้งหมดในบัญชี ใช้เทียบว่ามีตัวแปลกปลอมโผล่ไหม | อ้างอิงเท่านั้น |
| `bot-info.json` | ชื่อบัญชี โหมดตอบกลับ | อ้างอิงเท่านั้น |
| `greeting-message.txt` | ข้อความทักทายเพื่อนใหม่ | คัดลอกไปวางในแอป LINE OA ด้วยมือ |

## คำสั่ง

```bash
npm run line:check     # ตรวจว่าเมนูยังอยู่ครบ ผู้ติดตามไม่ลด โหมดไม่เพี้ยน
npm run line:backup    # ดึงของสดจาก LINE มาทับไฟล์ในโฟลเดอร์นี้
```

`line:check` คืน exit code 1 เมื่อพบปัญหา เอาไปต่อ cron หรือ CI ได้เลย

## ข้อจำกัดที่ต้องรู้

**LINE ไม่มี API สำหรับอ่านหรือเขียนข้อความทักทาย** ตัวตรวจจึงบอกไม่ได้ว่า
ข้อความทักทายยังอยู่หรือหายไป ต้องเปิดแอป LINE Official Account Manager
ดูเองที่ ตั้งค่าตอบกลับ > ข้อความทักทายเพื่อน

นี่คือช่องโหว่เดียวกับที่ทำให้ครั้งก่อนหายไปโดยไม่มีใครรู้ ควรเปิดดูด้วยตา
อย่างน้อยเดือนละครั้ง หรือทุกครั้งที่ยอดคนทักตกผิดปกติ

## วิธีตั้งข้อความทักทายกลับ

1. เปิดแอป LINE Official Account Manager เลือกบัญชีร้าน
2. ไปที่ ตั้งค่าตอบกลับ แล้วเปิดสวิตช์ ข้อความทักทายเพื่อน
3. กด สร้างใหม่ แล้ววางเนื้อหาจาก `greeting-message.txt`
4. บันทึก แล้วทดสอบด้วยการให้คนที่ยังไม่เคยแอด สแกน QR เข้ามาดู

ถ้าแก้ข้อความในแอปแล้ว อย่าลืมอัปเดต `greeting-message.txt` ตามด้วย
เพราะไฟล์นี้ดึงอัตโนมัติไม่ได้
